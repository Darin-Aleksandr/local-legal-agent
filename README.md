# ⚖️ ЮрАгент · ОСАГО

Локальный ИИ-агент для юриста по спорам ОСАГО. Работает на обычном ноутбуке с видеокартой, без подписок
и без отправки документов клиентов в облако.

Юрист делает две вещи: **кладёт документы во «Входящие»** и **пишет задачу словами**. Остальное агент делает сам:

- раскладывает сканы, фото, PDF и Word по делам, распознаёт текст и вытаскивает факты — каждый с цитатой из документа;
- сам скачивает свежие редакции законов и практику ВС и КС с официальных сайтов, раз в сутки;
- находит противоречия между позициями и применяет более сильную и более свежую;
- считает неустойку, штраф и госпошлину кодом, с расшифровкой каждой цифры;
- собирает претензию, обращение к финансовому уполномоченному и иск в DOCX и PDF;
- проверяет PDF по требованиям ГАС «Правосудие», пока файл ещё не ушёл в суд.

> Агент — инструмент юриста, а не юрист. Каждый документ перед подачей читает и подписывает человек.
> Всё, в чём агент не уверен, помечено **[ПРОВЕРИТЬ]** и собрано в список на последней странице черновика.

## Почему не просто ChatGPT или Gemini

Проект вырос из реальной «карты отказов»: того, что ломалось при работе с чат-ботами.

| Что ломалось | Как устроено здесь |
|---|---|
| Чат «забывает» дело, исправленные файлы теряются | Дело хранится в папке на диске: `dossier.json`, исходники, версии, журнал. Новая сессия начинает с чтения досье |
| OCR прочитал «Сурчаев» вместо «Сургаев», ошибка ушла во все документы | Распознанное считается гипотезой, пока человек не нажал «Подтвердить». Подтверждённое распознавание не перезаписывает, а расхождение попадает в заметки |
| Нейросеть придумывает номера дел и цитаты | Факт без дословной цитаты из документа отбрасывается. Довод без ссылки на фрагмент библиотеки удаляется. Номер дела, которого нет в библиотеке, заменяется на [ПРОВЕРИТЬ] |
| Цена иска в тексте, в пошлине и в расчёте разная | Все суммы считаются один раз, функциями в `calc.py`, и подставляются во все места. Сменили дату — пересчиталось всё |
| Устаревшая практика | Библиотека обновляется сама. Новая редакция закона вытесняет старую. Позиция, которую перекрыл КС или Пленум, исключается из поиска |
| ГАС отклоняет файл: «нет связного текста», «страницы перевёрнуты», «несколько документов в файле» | Валидатор проверяет каждое требование до выдачи. `lexagent fix` поворачивает страницы, добавляет текстовый слой и называет файл по правилам |
| Скан открывается вверх ногами | Страница рендерится так, как её видит человек, а ориентация определяется по тексту |
| Споры о подлинности поданного файла | Замороженный файл получает SHA256 в журнале дела |

## Установка (Windows 10/11)

Нужно: видеокарта NVIDIA с 8 ГБ памяти (проверено на RTX 4060), 16 ГБ ОЗУ (лучше 32+), около 15 ГБ на диске.

1. Скачайте проект: зелёная кнопка **Code → Download ZIP**, распакуйте, например, в `C:\ЮрАгент-программа`.
2. Правой кнопкой по `install\windows.ps1` → **Выполнить с помощью PowerShell**.
   Скрипт поставит Ollama, Tesseract с русским языком, LibreOffice и uv, скачает модели (~7 ГБ) и создаст ярлык на рабочем столе.
3. Запускайте **ЮрАгент** с рабочего стола. Окно откроется в браузере по адресу http://127.0.0.1:7860.
   Оно работает только на этом компьютере, снаружи недоступно.

Проверить, что всё на месте: `uv run lexagent doctor`.

## Как работать

**Вкладка «Задача».** Перетащите файлы и напишите, что нужно:

```
разбери входящие
сделай претензию по Сургаеву
посчитай неустойку по делу РЕСО на 01.12.2026
обращение к ФУ по Иванову
иск по Сургаеву
что ВС говорит о смене формы возмещения без согласия потерпевшего?
проверь файлы для ГАС
обнови библиотеку
```

**Вкладка «Дела».** Таблица фактов дела: значение, источник (файл, страница, цитата) и статус. Проверьте распознанное, при
необходимости исправьте и нажмите «Подтвердить». Здесь же кнопки «Претензия», «Обращение к ФУ» и «Иск».

**Вкладка «Библиотека».** Какие законы и какая практика сейчас в базе, какие редакции ушли в архив, какие противоречия
найдены и что применяется.

Документ появляется в папке дела, в `work/vNN/`:

- `Исковое заявление.docx` — черновик для правки, на последней странице расчёт и список [ПРОВЕРИТЬ];
- `Исковое_заявление_от_ДДММГГГГ_Nл.pdf` — файл для подачи, уже проверенный валидатором ГАС;
- `превью/` — картинки страниц, чтобы глазами убедиться, что всё на месте.

## Папки

```
ЮрАгент/
  Входящие/            ← сюда кладёте файлы; ссылки на практику — в ссылки.txt
    _разобрано/          разобранное переезжает сюда по датам
  Дела/
    2026_Сургаев_РЕСО/
      dossier.json      факты дела: значение, источник, подтверждено ли
      originals/        исходники, только для чтения, с SHA256 в hashes.json
      text/             распознанный текст
      work/v01, v02…    версии документов
      exports/          замороженные файлы для подачи
      logs/audit.log    журнал: что, когда и почему изменилось
  Библиотека/
    library.sqlite      законы и практика: редакции, фрагменты, противоречия
    отчёты/             что изменилось при каждом обновлении
```

## Откуда берутся законы и практика

Реестр источников лежит в [`sources.toml`](sources.toml), его можно дополнять без программирования:

- **законы** (40-ФЗ, 123-ФЗ, нужные статьи ГК, НК, ЗоЗПП). Агент следит за отметкой «ред. от …»: изменилась — скачивает
  заново, старая редакция уходит в архив;
- **ключевые документы** — Пленум ВС № 31, Обзор 2016 года, Постановление КС № 34-П;
- **поиск новой практики** — определения ВС, обзоры, решения КС, только с официальных доменов `vsrf.ru` и `ksrf.ru`.
  Документ без нужных слов («страхов», «транспортн») в базу не попадает.

Свою практику — решения по похожим делам, удачные образцы — можно просто положить во «Входящие»: агент сам поймёт, что
это не документ клиента, и отправит в библиотеку. Ссылку можно вписать в `Входящие/ссылки.txt`.

### Правило старшинства

Когда два фрагмента об одном и том же расходятся (это проверяет нейросеть, а решение принимает код):

```
КС РФ  >  Пленум ВС  >  Обзор Президиума ВС  >  определение ВС  >  кассация  >  апелляция  >  первая инстанция  >  свои материалы
```

Внутри одного уровня применяется более поздний документ. Проигравший фрагмент исключается из поиска, а в отчёте пишется,
что применяется и почему. Для законов действует только последняя редакция.

Почему это важно: 26.05.2026 КС принял Постановление № 34-П о лимите ответственности страховщика по ОСАГО, и часть
практики ВС конца 2025 года по этому вопросу перестала быть опорой. Агент, который скачал практику «один раз», продолжал бы
на неё ссылаться.

## Расчёты

`calc.py` — чистые функции, покрытые тестами:

- срок страховщика 20 дней без нерабочих праздничных (п. 21 ст. 12 Закона об ОСАГО);
- неустойка 1% в день с учётом частичных выплат, с ограничением страховой суммой 400 000 (п. 6 ст. 16.1);
- штраф 50% (п. 3 ст. 16.1);
- госпошлина по шкале ст. 333.19 НК РФ в редакции с 08.09.2024, льгота потребителя до 1 млн (ст. 333.36),
  жалоба для физлица 3 000;
- сумма прописью.

Ущерб сверх 400 000 агент к страховщику не предъявляет. Он помечает эту часть для предъявления виновнику
(ст. 1072 ГК РФ) и просит сверить позицию с отчётом библиотеки.

## Ограничения (честно)

- Модель на 9 млрд параметров хорошо вытаскивает поля и пишет абзацы по найденным источникам, но не заменяет
  юриста в стратегии. Поэтому стратегия, суммы и ссылки контролируются кодом.
- Сайты судов и КонсультантПлюс иногда меняют вёрстку. Если источник перестал отвечать, это видно в отчёте библиотеки:
  «адрес устарел», и нужно поправить адрес в `sources.toml`.
- Шаблоны документов — базовые. Под стиль конкретного юриста их правят в `src/lexagent/documents/compose.py`.
- Это не юридическая консультация. Ответственность за поданный документ несёт тот, кто его подписал.

## Для разработчиков

```bash
uv sync --extra dev
uv run pytest --cov=lexagent      # 79 тестов, покрытие ~92%; нейросеть в тестах — заглушка
uv run ruff check src tests
uv run lexagent ui --no-browser
```

Устройство:

| Модуль | Что делает |
|---|---|
| `cases.py` | дело на диске: досье, исходники, версии, журнал |
| `inbox.py` | разбор входящих: тип документа, дело, факты с цитатами |
| `textio.py` | текст из PDF, сканов, фото, Word; OCR с автоповоротом |
| `library/` | хранилище (SQLite FTS5 + векторы), загрузка, обновление, старшинство |
| `calc.py` | вся арифметика |
| `documents/` | сборка документов, DOCX и PDF |
| `gas.py` | валидатор и исправление файлов для ГАС «Правосудие» |
| `agent.py` | понимает задачу и вызывает нужное |
| `ui.py`, `cli.py` | окно в браузере и командная строка |

Нейросеть подключена через [Ollama](https://ollama.com): по умолчанию `qwen3.5:9b` для текста и `bge-m3` для поиска по
смыслу. Модели меняются в `config.toml`.
